Release 0.16.0#

Release summary#

statsmodels is using github to store the updated documentation. Two versions are available:

  • Stable, the latest release

  • Development, the latest build of the main branch

Bug Fixes#

  • The tricube kernel in statsmodels.nonparametric.kernels returns 0 outside of its support, \(|u| > 1\), instead of the peak value. Results of KernelReg and KernelCensoredReg that use ckertype="tricube" change. Issue #10541

  • The default value of power_poisson_ratio_2indep is now 1, the null hypothesis of equal rates. The previous default of 0 gave a power of 0, 1 or nan. The value must now be positive. Issue #10511

  • power_binom_tost returns a power of 0 instead of a negative value if the rejection region of the exact test is empty. Issue #10507

Breaking Changes and Deprecations#

  • The return_df argument of acorr_ljungbox has no effect, since the function always returns a DataFrame. Passing it now raises a FutureWarning, and it will be removed in statsmodels 0.17.0. Issue #8968

  • The linear argument of predict in BinomialBayesMixedGLM, PoissonBayesMixedGLM and BayesMixedGLMResults is deprecated in favor of which, matching predict. Use which="linear" instead of linear=True and which="mean" instead of linear=False. Passing linear now raises a FutureWarning, and it will be removed in statsmodels 0.17.0. Issue #8562
